# Amazon Clone

This project is a front-end clone of the Amazon homepage created for learning and practice purposes. It replicates the basic layout and design of Amazon using HTML and CSS.

## Features
- Amazon-inspired homepage layout
- Navigation bar
- Hero section
- Product cards
- Footer section
- Clean and organized code

## Technologies Used
- HTML5
- CSS3

## Purpose
The purpose of this project is to improve my front-end development skills by recreating a real-world website layout.

## Note
This project is created for educational purposes only. It is not affiliated with or endorsed by Amazon. The website is currently **not responsive** and is best viewed on desktop screens.
